# Gold-set

Размеченный набор вопросов для измерения качества поиска и ответов.

## Файлы

| Файл | Назначение |
|------|------------|
| `schema.json` | Контракт полей кейса |
| `examples.jsonl` | Короткие обучающие примеры (не обязательно гонять в eval) |
| `dataset.jsonl` | Рабочий набор — его пополняем |
| `validate_gold_set.py` | Локальная проверка формата |

## Добавить кейс

1. Допишите одну JSON-строку в `dataset.jsonl`.  
2. Проверьте:

```bash
python phase-0-discovery/gold-set/validate_gold_set.py
```

Подробный «как» и «зачем» — в туториале: [Шаг 5](../../docs/tutorials/00-discovery.md#шаг-5-gold-set--измерительная-линейка).
