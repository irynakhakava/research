# ADR-0008 · Offline experiments (фаза 4)

- **Статус:** accepted  
- **Дата:** 2026-09-07  
- **Связь:** [туториал](../docs/tutorials/04-experiments.md)

## Решение

Сравниваем **на том же gold-set и том же индексе e5**, без нового HTTP-сервиса.

| Ось | Что меняем | Метрики |
|-----|------------|---------|
| Режим поиска | `hybrid` / `dense` / `bm25` | Recall@k, MRR |
| Порог refuse | `min_dense_score` | refuse-rate, answered-rate, grounded среди отвеченных |
| Ширина контекста | `top_k` чанков в `/ask` | те же /ask метрики |
| Генератор | extractive (default); openai только если есть ключ | те же |

## Почему не качаем вторую модель эмбеддингов в baseline

`bge-m3` / смена e5 требуют пересчёта `embeddings.npz` + индекса. Это отдельный прогон, не сетка «из коробки».  
Харнесс умеет работать с уже собранным индексом; смена модели — вручную `run_embed.py` + `run_index.py`, затем этот же runner.

## Почему не полный cartesian

3 режима × 3 порога × 2 top_k × 25 вопросов слишком долго для локального демо. Сетки **независимые**: режимы отдельно, параметры `/ask` — своей таблицей.
