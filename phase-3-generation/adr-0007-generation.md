# ADR-0007 · RAG generation /ask (фаза 3)

- **Статус:** accepted  
- **Дата:** 2026-09-07  
- **Связь:** [туториал](../docs/tutorials/03-rag-generation.md)

## Решение

| Параметр | Значение |
|----------|----------|
| Контракт | JSON как у будущего HTTP `POST /ask` |
| Baseline-генератор | **extractive** — ответ склеивается только из retrieved-чанков + маркеры `[n]` |
| Опционально | `backend: openai` (Chat Completions, ключ `OPENAI_API_KEY`) |
| Цитаты | каждый ответ: `citations[]` с `path` и `url` |
| Низкая уверенность | `refuse_with_nearest_links` (NFR): отказ + до 3 ближайших документов без фактов |
| Секреты / не-доки | отказ **до** генерации по тексту вопроса |

## Почему extractive по умолчанию

Проект static-only и локальный (как e5). LLM API не обязателен для демо и тестов.  
Extractive не добавляет фактов «из параметров модели» — это закрывает риск галлюцинаций на MVP.

Сравнение промптов/моделей — фаза 4.

## Цитаты

- `path` — из `documents.jsonl` (файл в `data/corpus/…`)  
- `url` — `catalog.location` + `#doc_id` (демо-URL NordLedger, не живой Confluence)

## ACL

Фильтры фазы 2 применяются **до** передачи чанков в генератор. В промпт/ответ не попадают чужие чанки.
