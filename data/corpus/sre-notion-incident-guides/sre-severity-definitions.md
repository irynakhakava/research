# Severity definitions

| Level | Описание |
|-------|----------|
| Sev-1 | Полный простой критичного платежного пути |
| Sev-2 | Частичная деградация, значимый % ошибок |
| Sev-3 | Ограниченный импакт, есть workaround |
| Sev-4 | Малый дефект, плановый фикс |
