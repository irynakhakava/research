# api-gateway

Единая точка входа внешнего HTTP/JSON трафика.

- **Repo path:** `services/api-gateway/`
- **Auth:** API keys via identity-service
- **Docs:** внутренний portal `https://portal.nordledger.example/gateway`

Ошибки 401/403 описаны в runbook gateway-auth (wiki PLAT).
